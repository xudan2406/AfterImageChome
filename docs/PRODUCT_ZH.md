# AfterImage 中文产品介绍

AfterImage 是一款注重隐私的 Chrome 图片工作台，可在浏览器本地完成图片检查、格式转换、压缩、缩放和批量处理。

## 主要功能

- 通过文件选择器或拖放导入图片，单次批次最多 100 张。
- 从文件内容识别 JPEG、PNG、WebP 和 AVIF，不依赖文件扩展名。
- 转换为 JPEG、PNG 或 WebP；只有浏览器真实支持 AVIF 编码时才开放 AVIF 输出。
- 调整输出质量和尺寸，保持宽高比，并设置 JPEG 透明区域的背景色。
- 使用 Web Worker 处理图片；可以取消任务、重试失败任务。
- 下载单张结果，或在独立 Worker 中生成 ZIP。
- 在本机 IndexedDB 中保存最近处理结果；支持下载、单项删除和清空历史。
- 网页图片右键操作仅在用户主动选择后申请该图片所在站点的权限。网站策略可能阻止获取。

## 隐私与限制

本地图片处理不会把图片上传到 AfterImage 服务。处理结果与任务信息保存在当前浏览器设备中。右键获取网页图片时不会携带 Cookie 或 Referer，不跟随重定向；跨域限制、网站权限和浏览器能力都可能导致获取失败。

单张输入图片上限为 100 MB，解码图片上限为 1 亿像素；单批次最多 100 张、输入和输出各自不超过 500 MB；ZIP 导出上限为 500 MB。实际可处理范围还取决于浏览器支持和设备内存。

当前扩展界面为英文，简体中文运行时界面尚未实现。
