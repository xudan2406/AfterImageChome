# Chrome Web Store listing (English)

## Name

AfterImage — Private Image Workspace

## Short description

Convert, resize, compress, and batch-process images locally in your browser.

## Detailed description

AfterImage is a focused image workspace built for everyday image tasks—without uploading your local files to a processing service.

**Work with images**
- Import one image or a batch of up to 100 images.
- Convert between JPEG, PNG, and WebP. AVIF output is available only when your browser supports its encoder.
- Adjust output quality, resize dimensions, preserve aspect ratio, and choose a JPEG background for transparent images.
- Choose a batch preset for common format/quality settings, then adjust the shared values. Presets do not invent platform-specific dimensions.
- Crop by dragging over the image or entering pixel bounds; rotate, flip, and undo/redo edits in the local Editor.
- Compare actual input and output sizes, then download an individual result or export the batch as a ZIP.

**Keep work close**
- Image inspection and processing run locally in your browser using Web Workers and Canvas APIs.
- Recent results are stored in local browser storage and can be downloaded or deleted at any time.
- Right-click a webpage image to open it, convert it, compress it, or add it to a batch. AfterImage requests access to that image's site only when you choose the action. The site may block access.

**Limits and compatibility**
- Up to 100 MB per input image and 100 megapixels per decoded image.
- Up to 100 images and 500 MB of input and output per batch; ZIP export is limited to 500 MB.
- Supported output formats depend on your browser. AVIF encoding is not available in every browser.

AfterImage does not include accounts, analytics, or image uploads. Read the [privacy policy](https://xudan2406.github.io/AfterImage/) for data handling and permission details.
